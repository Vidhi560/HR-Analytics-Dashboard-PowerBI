# HR Analytics Dashboard | Power BI

## Project Overview

This project presents an interactive HR Analytics Dashboard developed using Microsoft Power BI. The dashboard provides valuable insights into workforce demographics, employee attrition, compensation, performance, and career growth. It helps HR professionals identify trends, monitor key metrics, and support data-driven decision making.

The dashboard is built using the IBM HR Analytics Employee Attrition dataset and demonstrates data cleaning, DAX measures, data modeling, and dashboard design skills.
